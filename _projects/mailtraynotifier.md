주요 기능

- 다중 메일 계정 지원 (최대 10개 계정)  
- 새 메일 발생 시 Windows 토스트 알림 표시  
- 최대 10개 계정까지 지원.  
- Windows 토스트 알림을 클릭하지 않으면 동기화 시간마다 계속 알림 표시.  
- 트레이 아이콘 우클릭 메뉴(알림 중지, 알림 시작, 설정, 종료)

## 제한 사항

- 30일 이전 메일까지 지원.  
- IMAP 미지원 (POP3만 지원)
